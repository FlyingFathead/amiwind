# AmiWind v0.0.50-dev2: the version-only proof (in development)

Development snapshot, 24 October 2026, in development. Running on CHIM Engine v0.2.2. Previous release:
[v0.0.49](RELEASE-v0.0.49.md).

This snapshot differs from [v0.0.50-dev1](RELEASE-v0.0.50-dev1.md) only in its version number (the version file, the
emulator presets, these notes and the version line of the generated pages). Its build checks the rule that a version
change rebuilds only the engine and the image: the CHIM world and every other stage must come from the dev1 build's
caches. The door work of v0.0.50 is not in it.

## Known in this build

- Everything in [v0.0.50-dev1's known items](RELEASE-v0.0.50-dev1.md#known-in-this-build) still applies.
- Everything else is in the [bug register](../../BUGS.md).
