works, the report template and the rules: [bug tracking](bugs/README.md).

[docs/bugs](bugs/README.md).

by hand. Change the JSON (or use `tools/bug_register.py add` / `set`), then run
`tools/bug_register.py render`. A test fails if the two disagree.

`fixed` means a correction shipped in the named version with supporting
verification; candidates and mitigations stay `open`. `closed` means not a bug,
a duplicate or superseded (the status says which).
