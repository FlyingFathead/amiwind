# Trackers

_Last updated with AmiWind v0.0.60-dev3 (4 November 2026)._

These three pages were written for the first image builds (v0.0.31 and v0.0.32) and describe the first version of the
world progress, entity and points-of-interest views. They have not followed the project since: the state of the
conversion is now kept by the trackers below, which have a source file and a check of their own. None of the three
pages holds game data; they hold cell coordinates, record IDs, counts and AmiWind's own status.

| Where the state is kept now | What it shows |
| --- | --- |
| [Game features](../GAME_FEATURES.md) | every system of the base game: its state, its reference and its proof, with the share done per area |
| [Cell by cell](../chim/CELL_TRACKER.md) | every cell of the world, converted and audited |
| [CHIM progress](../chim/PROGRESS_TRACKER.md) | the island by region |
| [Asset coverage](../ASSET_COVERAGE.md) | what of the original's assets is integrated |
| [Points of interest checklist](../POI_CHECKLIST.md) | every named place and whether it is converted |
