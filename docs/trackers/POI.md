# Points of interest

**Status: checklist available; in-game `dbg poi` menu planned.**

- **Checklist:** `tools/poi_checklist.py` lists every named place in your own
  Morrowind data, from cellars to cities, and marks which are converted. See
  [POI checklist](../POI_CHECKLIST.md).
- **Planned `dbg poi`:** a debug menu listing the converted points of interest;
  choosing one teleports there, and the last visited place is remembered on
  disk so an inspection round can continue where it stopped.

Both feed the [world progress tracker](WORLD_PROGRESS.md).
