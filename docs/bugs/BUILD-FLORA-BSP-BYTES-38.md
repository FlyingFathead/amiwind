_Last updated with AmiWind v0.0.42-dev1 (17 October 2026)._

## Symptom

Full-world preparation stops at world-flora with FloraReserveError. The run processed 2,551 regions and reported two failed maps. No completed playable image was produced.

## Where

Legacy exterior flora BSP maps vf1099 and vf2551, source revision 026caf436213cba3f44d0554be46fdb1a29bd0f9.

## How it happened

The generated BSP byte sizes exceed the 4,194,304-byte gate. vf1099 uses 4,266,352 bytes (72,048 over); vf2551 uses 4,344,664 bytes (150,360 over). Byte size was the reported failing constraint. The detailed content cause is still under investigation; overlap is not established as the cause.

## Why it was not caught

Earlier isolated conversion checks did not establish that every remaining legacy exterior map fits the full-build BSP budget. Converting one failing cell does not prove that the remaining maps fit.

## Reproduction

Run full-world preparation from the recorded source with the 363-cell CHIM selection and inspect world-flora/conversion-status.json and the failed maps' budget receipts.

## Repair

Pending: identify each map's authoritative cell ownership, validate its CHIM replacement and rebuild using only routed map payloads. Preserve content and the storage gate; do not silently omit references or include unused legacy duplicates.

## Verification

The build failure and byte counts are recorded. No successful replacement build, final image readback or native traversal is claimed.

## Prevention

Audit every remaining legacy map against its actual packed budget and reconcile runtime routing with the final package. An isolated CHIM pass is not full-world acceptance.
