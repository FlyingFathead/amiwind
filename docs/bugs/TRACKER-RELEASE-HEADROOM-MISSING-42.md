## Symptom
Preparing the v0.0.42 CHIMport batch by weight: every memory headroom figure in the tracker data came from CHIMport
or full builds of 11-14 October (v0.0.36 to v0.0.40 builders). The v0.0.41 release run (16 October, 723 region
cells) was ingested, but none of its cells carried a headroom figure, and the cells it shares with an earlier
CHIMport run showed that run's audits.

## Where
`tools/cell_progress_chim.py` `digest`: the memory audit of a full build was written once per run as text ("least
headroom N B", the run's minimum), with no figure per cell. `tools/cell_progress.py` `ingest`: CHIMport result files
are applied after every run digest, whatever their dates, so an older result replaced a newer build's audit.

## How it happened
The digest was written for one-area runs, where the run's least headroom is the cell's. Result files were meant to
win because they were the newest measurement when the order was made; full builds later measured cells again.

## Why it was not caught
No test fed a run and an older result for the same cell; the tracker page shows the audit status, not its build.

## Reproduction
Ingest a full build together with an older CHIMport result for one of its cells: the cell shows the result's
build and figure, and no cell of the full build has `memory_fit.numbers.least_headroom`.

## Repair
- Each frame's own ring figures (least headroom, peak, budget, load-ring headroom, the frame's verdict) go to the
  cells it converts.
- A CHIMport result older than the full build that last converted the cell does not replace that build's audits;
  a newer result still does.
- The CHIMport order by weight (`tools/chim_weight_table.py`) reads the current runs' heap reports directly and
  names the build and date of every figure.

## Verification
`tests/test_cell_progress.py` (`test_a_full_run_records_each_cells_headroom_from_its_frame`,
`test_an_older_chimport_result_does_not_replace_a_newer_full_runs_audit`); pending: the tracker ingested again with
the v0.0.41 release run.

## Prevention
Every figure in the weight table carries its build and date, and a figure from an older builder is marked so.
