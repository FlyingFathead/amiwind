_Last updated with AmiWind v0.0.42 (17 October 2026)._

## Symptom

The new pulsing selection outline was enlarged and displaced from cell boundaries.

## Where

Toolkit World map, including direct cell links on displays with device pixel ratio other than one.

## How it happened

The DOM overlay used the canvas backing-store scale, which includes device pixel ratio. DOM positions and dimensions instead require CSS pixels.

## Why it was not caught

The initial check confirmed selection and checkbox behavior but did not correctly verify alignment against the cell edges.

## Reproduction

Open a direct cell link on a scaled display and compare the outline with the selected grid square.

## Repair

Use the existing map layout CSS scale for the overlay. Keep canvas backing-store scaling unchanged. The animation affects only the overlay; reduced-motion preferences get a steady outline.

## Verification

Live browser inspection verified the outline on cell (3,-3), matching boundaries after zoom and controls-panel resizing. The checkbox hides and restores it. Maintainer confirmed the cell is now visible. This is browser evidence, not a packaged release claim.

## Prevention

Check CSS and device-pixel coordinate systems separately when adding overlays; verify selected-cell boundaries as well as visibility on scaled displays.
