_Last updated with AmiWind v0.0.42 (17 October 2026)._

## Symptom

The inventory's category row (All, Weapons, Armour, Clothing, Potions, Ingredients, Books, Misc), the sort line
and the footer are drawn in the console font as plain text. In the original game the categories are buttons
with the game's own font. The maintainer asked for the game's font in the inventory on 14 October 2026 and
again on 17 October 2026.

## Where

The inventory screen (engine/aga/src/aw_worldui.c) and its font settings (docs/INVENTORY.md).

## How it happened

The inventory was built in steps (UI-INVENTORY-LAYOUT-40, then the original title bar and icons in v0.0.42).
The configurable inventory font was recorded on 14 October but not implemented.

## Why it was not caught

The inventory tests check the layout and the text, not the font or the button frames against the original.

## Reproduction

Open the inventory (I) in v0.0.42-dev1.

## Repair

Planned: the category row as button tabs with the original menu art, labels in the game's font, as the original
lays them out (OpenMW 0.51 inventory window as the logic reference).

## Verification

Not yet repaired.

## Prevention

A layout test that the category row uses the game font and the button frames.
