## Status: 10 October 2026

Fixed in source on the v0.0.35 line (counted per frame and shown in dbg rcount ("nv") and the chim command). Not yet in a build.

## Symptom

Leaves of the grid and void, and chunks whose row is missing, keep no visibility data, so the renderer treats everything as visible while the eye is there.

## Where

CHIM engine chim_chunks.c (link pass), chim_world.c dbg rcount.

## How it happened

The fallback is Quake's (no row = all visible); nothing reported it.

## Why it was not caught

Performance checks read the visible share from map data, not per frame.

## Reproduction

Native host test native world tests (rcount fields) and the gate suite in tests/test_chim_engine_native.py (or the zone and heap tests named there); before the repair it fails.

## Repair

Every frame whose view leaf has no visibility row is counted; dbg rcount shows the count since its last line ("nv") and the chim command the total, so a frame-rate drop can be traced to it.

## Verification

Native host tests (compiled with AddressSanitizer and UndefinedBehaviorSanitizer) and the full gate. Not yet seen in a build.

## Prevention

The test stays in the native suite; the failure becomes a failed load, a wait or a counted fallback instead of the end of the map.
