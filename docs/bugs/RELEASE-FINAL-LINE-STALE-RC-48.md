_Last updated with AmiWind v0.0.48 (24 October 2026)._

## Status: 24 October 2026

Open. Fixed by hand for v0.0.48: the rc1 line was merged into the final line before the gate, so the released
source (41820ef3) contains the image's source commit (af1df936).

## Symptom

The v0.0.48 final line (VERSION, release notes, changelog, presets) was started from the rc1 head 1f862118. The rc1
image was then built from af1df936, which added two image layout fixes (IMAGE-LAYOUT-PLAN-ACTOR-LIBRARY-48). Without
the merge, the public source would have had a builder that could not lay out the image that shipped.

## Where

The release flow: the final commit against the release image's source commit.

## Repair

The release guard checks that the image's source commit is an ancestor of the release commit, and that no commit
between them touches a build input (only VERSION, notes, changelog, presets and register files).

## Verification

A guard run on a release commit that does not contain the image commit fails with the named check.
