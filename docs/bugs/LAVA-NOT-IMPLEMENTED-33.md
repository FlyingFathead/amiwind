## Status: 9 October 2026

Open. Census done (`tools/lava_census.py`); the liquid conversion, damage and view tint are being built on the
next-release line ([LAVA.md](../LAVA.md)).

## Symptom

Morrowind's molten lava (the `in_lava_*` pools) never became a Quake liquid. The interior room converter leaves
the pool activators out altogether ("unsupported activator", `select_geometry`), so a lava cave would have no lava
at all; the exterior frame converters place the pool mesh as an ordinary solid model with a self-lit texture. Either
way: no warp, no damage, no view tint and no lava sound, and the player walks across the pool like rock. The roadmap promised lava fields since v0.0.29, but no area, census or overlay
covered them.

## Where

The converters (interior rooms `tools/prepare_area.py`, exterior frames, CHIM chunks) and the engine's game logic.
The engine itself kept Quake's liquid support all along: `*` warp textures (`SURF_DRAWTURB`, `Turbulent8`),
`CONTENTS_LAVA`, the lava colour shift in `view.c`.

## How it happened

Lava was planned three times (v0.0.29 study, the lighting source study, the roadmap's "fires and lava" entry) and
each time deferred as study work. No bug ID or tracker row recorded it, so every later area plan left it out.

## Why it was not caught

Roadmap and study text only: no register entry, no tracker layer, no converter test. No shipped area contains
molten lava (Balmora, Seyda Neen and the Vivec Arena have none), so no playtest met it.

## Reproduction

Convert any interior with a lava pool (for example Assemanu, the Dagoth Ur facility, Akulakhan's Chamber): the pool
is missing. Convert a Molag Amur exterior cell: the pool is a solid model.

## Repair

Planned in [LAVA.md](../LAVA.md): the census identifies molten lava from the game's own records (objects whose
script hurts a standing actor), the builder turns each pool into a Quake liquid brush with a `*lava` warp texture
made from the user's own lava textures, the engine applies Morrowind's damage and a blood-red view tint; the
previous behaviour stays selectable (`--lava static`: rooms leave the pool out, exterior frames place it as a model).

## Verification

Pending: census tests, converter tests (contents and textures), engine tests (damage and tint), then a MiniWind
lava sandbox with headless OpenMW reference frames at the same pose.

## Prevention

The lava census feeds a per-cell lava stat to the trackers (World Map "Lava" layer, CHIM Progress Tracker lava
audit), so every lava cell shows as mapped, converted or missing.
