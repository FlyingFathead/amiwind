## Status: 9 October 2026

Open.

## Symptom

Every build with `--reuse-from` lists "engine: compiles with the Amiga SDK, whose files are not fingerprinted
(about 15 s)".

## Where

`tools/build_cache.py`, the engine stage's fingerprint.

## How it happened

The SDK is an external tree; rather than hash it, the stage always runs.

## Why it was not caught

Always running is safe, so nothing failed; it is still an input the key does not declare.

## Reproduction

Any build with `--reuse-from`.

## Repair

Planned: the SDK compiler, assembler and libraries by content in the engine stage's key.

## Verification

Planned: a key-coverage test (a changed SDK file changes the key) and a rerun that reuses the engine.

## Prevention

No stage avoids reuse by always running; keys declare every input.
