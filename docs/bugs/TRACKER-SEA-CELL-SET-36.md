## Status: 10 October 2026

Repaired in source on v0.0.36-dev, not shipped.

## Symptom

The World Map's island view of the CHIM Progress Tracker leaves out 37 land cells around the coast: they hold the
game's terrain (deep seabed) and sea but nothing placed. CHIMport converts them (status empty sea), but they are
not counted with Vvardenfell; one of them, west of Vvardenfell, is even labelled as Solstheim.

## Where

`tools/cell_progress.py`, `ingest`: the island set of each cell.

## How it happened

The set of a cell was copied only from the map-metrics layer. That layer measures cells with placed objects, so a
cell with terrain and sea only has no metrics row and got no set; one metrics row carried the wrong island.

## Why it was not caught

The test island's metrics fixture covers every land cell, so no test cell lacked a metrics row.

## Reproduction

Always: a land cell (LAND record) without a metrics row; the tracker shows its set as empty.

## Repair

The set of a land cell now comes from the masters' own LAND records (base master = Vvardenfell, land only in
Bloodmoon = Solstheim); the metrics layer is only the fallback for cells without LAND.

## Verification

Test in `tests/test_cell_progress.py`: a land cell without a metrics row and a cell whose metrics name another
island both read Vvardenfell; a Bloodmoon-only land cell reads Solstheim.

## Prevention

The test covers cells without metrics rows and a disagreeing metrics layer.
