_Last updated with AmiWind v0.0.42-dev1 (17 October 2026)._

## Symptom

The combined v0.0.41 world build stopped while mounting four Nordic windows
from original cell (7, 22) into the adjacent frame apron. Their supporting
thatched tower was present, but the facade search accepted only model names
containing "house". Exact source triangles support all four windows under the
existing distance and outward-normal checks.

The candidate recognizes the original thatched-tower model in both local and
neighbouring facade searches. It keeps original reference ownership, geometry,
collision, mounting range and clearance. Arbitrary props are still rejected.
The failing build is preserved; complete conversion, native comparison and
fresh package readback remain pending. Coverage counts are not promoted.

## Where

Nordic decorative windows in original cell (7, 22), reached by frame (7, 21).

## How it happened

The local and neighbouring support filters used the substring "house".
The original common thatched tower has a different model name, so its valid
facade triangles never reached the existing mounting ray test.

## Why it was not caught

House and cross-cell fixtures passed. The wider regional apron first exposed
the tower's windows in the combined conversion. The fixture set lacked a tower.

## Reproduction

Select the Nordic windows and the common thatched tower together. The old
filter rejects the tower before testing its correctly oriented wall triangles.

## Repair

Recognize the exact common thatched-tower model alongside the existing house
selection in both source searches. Normalize path separators and case. Keep
the existing geometric checks and report the failing window reference ID.
AmiQuake's r_surf.c brush-surface renderer and original collision machinery
remain unchanged; the existing baked-panel placement path is reused.

## Verification

Read-only measurements of the retained failed build find supporting walls for
all four affected windows, with shifts between 1.18 and 1.76 runtime units.
Regression cases cover local tower support, neighbour loading and rejection of
unrecognized props. The 68 focused checks and exact 4,227-test suite passed, with three Windows
skips and three tracked expected failures. Combined conversion stopped at a
separate fixed-visibility scope failure; native and package gates remain pending.
The preceding source passed 4,225 tests with three Windows skips and three
tracked expected failures, plus the target compile. Those results do not
certify this subsequent converter change.

## Prevention

Keep original placement identity separate from support-only geometry. Test
approved architectural model types in both local and neighbouring searches.
Actual-game suspect-geometry snapshots and matched original comparison are
pending a complete fresh world image; no visual repair is claimed yet.
