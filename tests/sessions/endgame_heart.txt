# The end of the main quest with a test character (ENDGAME-HEART-SESSION-66; docs/GAME_RECORDER.md "Gameplay journeys",
# docs/SCRIPTED_ACTORS.md). A FULL image, FS-UAE at 32 MB Fast, started with --map seyda; one part, one session. Every check
# reads the game's state (console answers, the state file, the script status counts), never a picture.
#
# What the original asks (the scripts in the game data, read by the builder; OpenMW 0.51 for how they run):
# - Sunder (`sunder`, script ouch_sunder) and Keening (`keening`, ouch_keening) hurt the player every second while
#   equipped unless the global wraithguardEquipped is 1; Wraithguard (`wraithguard`, wraithguardScript) sets it while
#   worn. Carrying them advances C0_Act_C (Keening 10, Sunder 15).
# - The Heart of Lorkhan (`heart_akulakhan`, reference 197602, script LorkhanHeart; locals in slot order sunderHit,
#   keeningHit, countHits, countSays, doOnce) cannot die (its health set to 5000 every frame). When the player first comes
#   within 500 game units it moves Dagoth Ur (`dagoth_ur_2`, 262014) to -40 2590 -180 of the chamber and starts his fight.
#   It counts nothing until struck with Sunder (HitOnMe Sunder); then each Keening blow (HitOnMe Keening) adds one to
#   countHits and plays Idle2, Idle3, Idle4, Idle5; the fifth plays Death1 and sets the global HeartDestroyed.
# - Dagoth Ur (DagothUrCreature2) turns teleporting off, sets his health back to 1000 whenever it falls under it, and
#   changes his shield ability with the Heart's countHits (dagoth_ur_shield_01 at 0 .. none at 4); once HeartDestroyed is
#   1 his health is capped at 200 and his magicka emptied, so he can die.
# - The dreamer workers (dreamerWorkerScript) set their health to 0 when HeartDestroyed is 1.
# - Two invisible activators (`dagoth destroy detector`, 262016 by the entrance and 262017 off the bridge, script
#   DagothDoorDetector) start the global script EndGame once HeartDestroyed is 1, DestroyBlight is 0 and the player is
#   within 1200 game units: EndGame sets C3_DestroyDagoth to 20, plays Death1 on Akulakhan (`in_akulakhan00`) and the
#   bridge (`in_dagoth_bridge00`): the collapse, disables the blight cloud, changes the Red Mountain weather (ModRegion,
#   ChangeWeather), sets Dagoth Ur's and the ash vampires' health to 0, turns teleporting back on, sets DestroyBlight to
#   -1 and gives the player 10 reputation.
# - The quest ends in Dagoth Ur, Facility Cavern: Azura's spirit (`azura spirit`, 425529, script AzuraEnd) appears at
#   C3_DestroyDagoth 20, within 250 game units takes the controls, plays the ending video, then sets C3_DestroyDagoth and
#   A1_SleepersAwake to 50, enables the Ring of Azura (`ring of azura`, 481184) and gives the controls back.
#
# How this session gets there: a test character (dbg aw hors: Hors after the census) with every attribute and skill at 100
# (dbg maxstats), the three tools given and equipped, the quest set to 10 (Dagoth Ur defeated in the Facility Cavern, the
# stage before the chamber), then dbg tp heartchamber. Dagoth Ur is FOUGHT IN GOD MODE, not killed by reference: his own
# script keeps him alive while the Heart lives (that is part of what is checked) and the original lets him be killed only
# after it. Map-local points are the room's own (game units / 4): the Heart at -2.9 967.6 -67.4, its model's middle at
# 0.7 967.5 -46 (the model's box), the platform in front of it with a standing origin at about -46 (the room's
# collision, tools/chim/room_scene.py, traced with the standing hull), the entrance at -24 320 473
# (config/teleport-names.txt), 72 units from the detector 262016. The player stands at 0 946.
# The Heart is set on the player first (chim actors fight), as the first blow would do, so the swing finds it by the
# original's hit cone over the fighters even when the crosshair's ray does not meet it.
# The ending's collapse is a known gap today: ENDGAME-CHAMBER-COLLAPSE-63 (Akulakhan and the bridge are part of the room's
# fixed geometry, so their Death1 finds nothing to play).
